# Max Training App

Персональное PWA для ведения тренировок по плану A1 → C → B1 → C → A2 → C → B2 → C.

Рабочий адрес: `https://training.everybodyloves.ru`

## Данные и приватность

- История тренировок, замеры и прогресс хранятся локально в браузере устройства.
- Репозиторий и сервер не содержат пользовательский журнал.
- Перед сменой телефона или очисткой Safari нужно сохранить резервную копию в разделе «Прогресс».

## Обновления

GitHub Pages публикует файлы из корня ветки `main`. Service worker обеспечивает установку PWA, офлайн-запуск и обновление версии.

## Версия 1.1

- Силовые тренировки и день C сохраняются в черновик после каждого изменения и восстанавливаются после навигации, сворачивания или перезапуска.
- Незавершённую тренировку можно продолжить или удалить с главного экрана.
- У упражнения можно оставить пометку «можно увеличить вес» (для гравитрона — уменьшить противовес); она показывается вместе с прошлым весом в следующий раз.
- В текущую тренировку можно добавлять упражнения, создавать свои и менять порядок блоков.
- Шкала прогрессии теперь текстом показывает текущий и следующий ориентир вместо элементов, похожих на кнопки.
